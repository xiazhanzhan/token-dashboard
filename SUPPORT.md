# Support

## Installation and usage questions

Use the **Installation help** issue form and provide only non-sensitive system
information. Before posting:

1. Read the relevant macOS or Windows Host guide.
2. Confirm whether the problem affects the Host, a remote Agent, or Tailscale.
3. Remove device names, user names, home-directory paths, Tailnet names,
   session identifiers, tokens, and account labels from screenshots and logs.

Never upload a real Token database, Codex/Hermes session file,
`agent-config.json`, configured Agent ZIP, or authentication credential.

## Bugs and feature requests

- Use **Bug report** for reproducible software defects.
- Use **Feature request** for new ideas and workflow improvements.
- Use GitHub Discussions for open-ended questions after Discussions is enabled.

## Security reports

Do not use a public issue for security vulnerabilities. Follow
[SECURITY.md](./SECURITY.md).
