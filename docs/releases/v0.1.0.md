# Token Dashboard 0.1.0 preview

The first public preview of a privacy-first, self-hosted Token usage dashboard
for Codex and Hermes across multiple devices and accounts.

## Highlights

- Daily, weekly, monthly, and yearly Token analytics.
- Codex and Hermes source comparison with normalized cache accounting.
- Multi-device and multi-account filters.
- Mac or Windows can act as the central Host.
- macOS and Windows remote Agents, including Hermes CLI data from WSL.
- Per-device write credentials, offline delivery queues, backups, and device
  revocation.
- Chinese/English dashboard UI and three coordinated themes.
- Local-only service binding with private Tailscale Serve deployment guidance.

## Download

- `Token-Dashboard-Host-macOS.zip`
- `Token-Dashboard-Host-Windows-x64.zip`
- `SHA256SUMS.txt`

Download the Host package for the computer that will store the dashboard
database and remain available to receive other devices.

## Verify downloads

macOS:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell:

```powershell
Get-FileHash .\Token-Dashboard-Host-Windows-x64.zip -Algorithm SHA256
```

Compare the Windows result with the matching line in `SHA256SUMS.txt`.

## Safety notes

- These generic Host packages do not contain a user database, real usage data,
  Tailnet address, or configured device credential.
- A configured single-device Agent ZIP is private. Never publish or forward it.
- Keep the dashboard on `127.0.0.1:8765` and use Tailscale Serve, not Funnel or
  public port forwarding, for remote access.
- Back up the dashboard database before testing upgrades.

## Known limitations

- The Windows Host has automated and static test coverage, but final
  end-to-end validation is still needed on representative Windows 10/11 x64
  systems.
- macOS may require explicit approval for Tailscale's network extension.
- Historical Hermes session totals may lack per-call timestamps and are
  assigned to the session start date during initial import.
- Codex and Hermes local storage formats are upstream implementation details and
  may require collector updates after upstream changes.
