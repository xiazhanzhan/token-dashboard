# Token Dashboard 0.1.2 preview

This security-focused preview strengthens the release supply chain and private
vulnerability reporting without changing Token accounting, the API, or the
local database schema.

## Highlights

- Every GitHub Action is pinned to an immutable commit.
- Workflow permissions are read-only by default; only the tagged-release job
  receives the minimum write permissions needed to publish and attest assets.
- macOS and Windows Host packages, plus `SHA256SUMS.txt`, receive GitHub build
  provenance attestations.
- The security policy links directly to private vulnerability reporting and
  documents best-effort acknowledgement and assessment targets.
- The test environment uses `pytest>=9.0.3,<10`.

## Download

- `Token-Dashboard-Host-macOS.zip`
- `Token-Dashboard-Host-Windows-x64.zip`
- `SHA256SUMS.txt`

Download the package for the computer that will store the central dashboard
database. Release packages contain no real Token data, Tailnet address, or
configured remote-device credential.

## Verify checksums

macOS:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Windows PowerShell:

```powershell
Get-FileHash .\Token-Dashboard-Host-Windows-x64.zip -Algorithm SHA256
```

Compare the Windows result with the matching line in `SHA256SUMS.txt`.

## Verify build provenance

With GitHub CLI installed, verify either downloaded Host package against this
repository:

```bash
gh attestation verify Token-Dashboard-Host-macOS.zip \
  --repo xiazhanzhan/token-dashboard
```

```powershell
gh attestation verify .\Token-Dashboard-Host-Windows-x64.zip `
  --repo xiazhanzhan/token-dashboard
```

A successful result confirms that the artifact was produced by this
repository's tagged release workflow. It does not replace reviewing the source
or keeping local credentials private.

## Safety notes

- Never publish or forward a configured single-device Agent ZIP.
- Keep the dashboard bound to `127.0.0.1:8765`.
- Use Tailscale Serve inside your Tailnet, not Funnel or public port forwarding.
- Remove credentials, real usage data, local paths, account names, session IDs,
  and Tailnet information before posting diagnostics.

## Known limitations

- Final end-to-end Windows 10/11 x64 Host validation is still requested from
  representative machines.
- macOS may require explicit approval for Tailscale's network extension.
- Historical Hermes session totals without per-call timestamps are assigned to
  the session start date during initial import.
- Codex and Hermes local formats are upstream implementation details and may
  require collector updates after upstream changes.
