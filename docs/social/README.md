# Social preview asset

`token-dashboard-social-preview.jpg` is a synthetic marketing illustration for
the repository's GitHub Social Preview. It contains no user data, device name,
account label, session identifier, Tailnet address, or credential.

Repository administrators can upload it from:

```text
GitHub repository → Settings → General → Social preview → Edit
```

The committed copy is intentionally below GitHub's 1 MB upload limit and uses a
2:1 aspect ratio.
